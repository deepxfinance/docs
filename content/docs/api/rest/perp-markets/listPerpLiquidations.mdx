          Returns liquidation records for one perpetual market across all
          subaccounts, with cursor pagination. Each record has `liqType:
          LIQUIDATE_PERP`, and `detail.marketId` identifies the requested
          market.

          Includes orderbook execution, incentivized takeovers, ADL fills, and
          records of cancellations only when they identify this market. Records
          with no market association remain available through `GET
          /v1/account/subaccounts/{address}/liquidations`.
