**Current API Version:** `1.7.0`

## Changelog

### v1.7.0 (2026-10-14)

- Split terminal order status into `CANCELED` (user-initiated) and `SYSTEM_CANCELED` (protocol-initiated).
- Orders always include `cancelReason` and `cancelBlockNumber`: `null` when not applicable. `cancelReason` is a closed enum, non-null exactly when `status` is `SYSTEM_CANCELED`. Spot orders gained these fields, matching perpetual orders.
- Order history endpoints accept a multi-value comma-separated `status` filter.
- Balance events always include `from`, `to`, `txHash`, `txHashType`, `blockNumber`, and `crossChain`; the chain-internal `eventIndex` is not exposed.
- Renamed `height` to `blockNumber` in balance events, liquidation records, and bankruptcy records, matching orders.
- Added `GET /v1/prices`: USDC-denominated index prices for every listed asset (perpetual, spot, and lending), with an optional `asset` filter, so balances can be valued in a single request.
- Added `GET /v1/perp/prices` and `GET /v1/perp/markets/{symbol}/prices`: REST snapshots of perpetual index and mark prices, counterparts to the `perp@prices` WebSocket channel.
- Added `GET /v1/account/subaccounts/{address}/bad-debts`: outstanding insurance-fund recovery claims per asset. Eligible wallet deposits automatically repay matching claims after existing borrowing is repaid.
- Added `GET /v1/stats`: protocol-wide statistics.
- Clarified when response values are calculated together and what `time` means.

### v1.6.0 (2026-10-05)

- Liquidation records cover orderbook execution, takeover, ADL, and order cancellations, with USDC fees and string order IDs.
- Perpetual markets and lending assets expose separate orderbook and takeover fee rates.
- `GET /v1/account/subaccounts/{address}/bankruptcy-records` reports account-level insurance fund payments.
- On-chain error codes match the runtime.
- Lending rate curves accept zero to five kinks.
- Removed the redundant delegate `active` field. Delegation permission is described by `mode` and `validUntil`.

### v1.5.0 (2026-09-24)

- Clarified perpetual-position and position-history price, quantity, and PnL semantics; added realized PnL and fees to open positions.


### v1.4.1 (2026-09-21)

- Added transfer-limit `status` (`AVAILABLE`, `RESTRICTED`, `UNAVAILABLE`) and made `maxTransferableQty` nullable; 

### v1.4.0 (2026-09-21)

- Added the per-asset transfer-limit endpoint with optional `autoBorrow`.
- Renamed withdrawal limits to transfer limits (`maxWithdrawableQty` → `maxTransferableQty`, `withdrawalLimits` → `transferLimits`).

### v1.3.0 (2026-09-20)

- Made `uniMMR` and `uniIMR` nullable when the corresponding margin requirement is zero.
- Renamed `maxWithdrawQty` to `maxWithdrawableQty`.
- Simplified withdrawal-limit status to `AVAILABLE` and `UNAVAILABLE`.

### v1.2.0 (2026-09-15)

- Added optional portfolio expansions for balances and per-asset withdrawal limits.
- Added asset filtering and the single-asset withdrawal-limit endpoint.
- Standardized account valuation amounts and asset prices as USDC-denominated.

### v1.1.0 (2026-06-13)

- Added cross-chain balance event support.
- Standardized EVM address naming and decimal financial fields.

### v1.0.0 (2026-03-24)

- Initial release.
